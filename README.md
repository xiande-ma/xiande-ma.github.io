# Xiande Ma personal homepage

GitHub Pages / Jekyll site files. Place all five site files at the root of the GitHub Pages repository, keeping the filenames exactly as they are:

- `_config.yml`
- `index.md`
- `publications.md`
- `cv.md`
- `child.jpg`

The **CV** navigation now leads to `/cv/`, generated from `cv.md` using Jekyll's `permalink: /cv/` front matter. The CV is a web page, not a PDF.

After committing the files to the repository, wait for the GitHub Pages build, then open the homepage and click **CV**. If the site's Pages source is configured as `/docs`, put the five files in that folder instead of the repository root.
